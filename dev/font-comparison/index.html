Implemented adjustments and next checks

1 · Correct the defaults

Default to Regular 400, strengthen tiny punctuation, and preserve the dotted zero and 600-unit advance.

2 · Tune for database work

Prioritize numbers, timestamps, operators and quoted identifiers. Avoid default SQL ligatures and overly decorative italics.

3 · Verify before adopting

Test 12–20 px on all three desktops, both Ayu themes, with EXPLAIN plans, UUIDs, metrics and real result grids.
